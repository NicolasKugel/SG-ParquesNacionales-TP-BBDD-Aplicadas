# Herramienta usada para diagramar DER

La herramienta usada para diagramar el DER es [DBML](https://dbml.dbdiagram.io/).

Para entender la sintaxis de DBML, consulta la [documentación](https://dbml.dbdiagram.io/docs).

Tiene funcionalidades para exportar el DER a diferentes formatos, como SQL, PostgreSQL, MySQL, entre otros.
